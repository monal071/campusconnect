01 / Introduction

Introduction

CampusConnect is a web-based platform designed to simplify communication, networking, and collaboration within educational institutions. It bridges the gap among students, faculty, and administrators by providing a centralized platform for sharing jobs, resources, and events.

The platform includes secure logins via NextAuth.js (Google Sign-In), connection requests, a role-based dashboard, a real-time quiz engine, community management, and file resources — all under one roof.

Built with React, Next.js, Node.js, and MongoDB, it aims to remove communication gaps by bringing all campus information together in one place, helping students, teachers, and administrators stay connected easily.

02 / System Analysis

System Analysis

⚠️ Problem Statement

  • 1Email Overload & Poor Classification: Campus updates and opportunities get lost in crowded inboxes or spam folders.
  • 2Campus Isolation: Students and faculty struggle to connect and share information within their institute.
  • 3Lack of Verified Job Platform: Students rely on unverified WhatsApp groups where fake job postings are common.
  • 4Resource Fragmentation: Study materials are scattered with no central access point.

✅ Proposed Solution

CampusConnect provides a central communication platform with clearly separated sections for jobs, resources, and events.

Student-to-student connections & networking
Verified faculty mentorship & profiles
Role-based dashboards (Student / Faculty / Admin)
Real-time notifications & chat
Secure file upload & resource management
Quiz creation with instant analytics
Community groups with invite codes

08 / Challenges

Challenges Faced

⏱️

Real-Time Quiz Synchronization

Keeping quiz state consistent across concurrent participants without WebSockets in a serverless environment.

✓ Redis + polling strategy
🔐

Role-Based Access Control

Implementing granular permissions for all 3 roles across 30+ API endpoints with middleware chains.

✓ Next.js Middleware + JWT claims
📂

Large File Upload Handling

Uploading large files reliably without blocking threads or timing out on Vercel's edge functions.

✓ UploadThing CDN integration
📊

Scalable Database Design

Designing MongoDB schemas for nested relationships without N+1 query issues.

✓ Aggregation pipelines + indexing
🚦

API Rate Limiting

Preventing abuse on public endpoints while not degrading legitimate user experience during peak hours.

✓ Redis sliding window limiter
🎨

Consistent UI Across Themes

Maintaining visual consistency across dark/light mode and mobile/desktop across 80+ components.

✓ next-themes + Tailwind vars
